# WebSocket VS API Rest

> Websocket foi utilizado pois mantem conexão, a API só faz a requisição, como quero acompanhar em Real Time faz mais sentido.

# Explicação do Payload do WebSocket da Binance

## e
> Tipo do evento.

## E
> Timestamp que a Binance enviou o evento.

## s
> Símbolo.

## t
> ID da trade.

## p
> Preço da trade.

## q
> Quantidade negociada naquela trade.

## T
> Timestamp em que o trade aconteceu.

## m
> Se o comprador era o market marker.

## M
> Campo legado.
